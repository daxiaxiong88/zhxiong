## 📂 项目结构

```
zhxiong/
├── index.html          # 主展示页（胶片 + 数码双分区）
├── admin.html          # 作品上传与管理后台
├── gallery/
│   ├── 胶片/           # 胶片摄影作品
│   ├── 数码/           # 数码摄影作品
│   └── images.json     # 照片元数据索引
└── README.md           # 本文件
```

## 🛠️ 技术要点

- **纯静态**：单文件 HTML，无构建依赖，直接部署 GitHub Pages
- **响应式**：手机 / 平板 / 桌面自适应布局
- **交互**：胶片横向拖拽滚动 + 数码网格瀑布流 + 全屏 Lightbox
- **后台**：通过 GitHub API 直接上传、删除作品，自动更新索引
